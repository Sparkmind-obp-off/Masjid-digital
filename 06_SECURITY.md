# SECURITY BASELINE

1. Public users cannot mutate data.
2. Admin routes require authentication.
3. Role checks server-side.
4. Validate every input.
5. Parameterized queries only.
6. Secrets in environment variables.
7. Never commit .env.
8. Minimize personal-data collection.
9. Log administrative mutations.
10. Backup/export before production.
11. HTTPS in production.
12. Generic authentication error messages.
