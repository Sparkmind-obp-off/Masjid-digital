# UI / UX SPEC

## Visual direction
Calm, clean, respectful, modern. Hindari ornamen berlebihan.

## Home
- Nama masjid
- Intro singkat
- Informasi utama hari ini
- Upcoming event
- CTA jadwal / kontak
- Pengumuman terbaru

## Event card
Title, speaker, date/time, location, description.

## Donation
Tujuan donasi, metode yang tersedia, dan kontak konfirmasi. Jangan memakai rekening/data nyata pada demo.

## Admin dashboard
Cards: agenda aktif, pengumuman aktif, pemasukan, pengeluaran, saldo periodik.

Tables: agenda terbaru dan transaksi terbaru.

## UX
Loading states, empty states, destructive-action confirmation, success feedback, accessible contrast, keyboard navigation.
