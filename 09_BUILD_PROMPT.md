# ONE-SHOT BUILD PROMPT

Build this repository into a production-ready MVP called "Masjid Digital".

GOAL:
Create a clean, respectful, mobile-first digital system for mosque information and basic administration.

MUST HAVE:
- Public homepage
- Mosque profile
- Events/kajian
- Announcements
- Donation information
- WhatsApp contact CTA
- Gallery
- Admin authentication
- Admin dashboard
- Event CRUD
- Announcement CRUD
- Finance CRUD
- Audit log
- Responsive UI
- Loading/empty/error states
- Server-side authorization
- Environment-based secrets
- Database migrations
- Clearly separated demo/production data

TECHNICAL:
Prefer Cloudflare-first deployment and free-tier services.
Use Cloudflare D1 when practical.
Keep architecture simple and maintainable.
Do not introduce paid dependencies unless unavoidable.
Do not hardcode secrets.
Document local development, deployment, environment variables, migrations, and admin setup.

DELIVERY:
1. Implement.
2. Run tests/build.
3. Fix errors.
4. Produce deployment instructions.
5. Produce a concise implementation report and known limitations.

IMPORTANT:
Do not invent real mosque names, financial accounts, addresses, or personal information. Use clearly marked demo data until real data is provided.
