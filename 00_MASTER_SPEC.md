# MASTER SYSTEM SPEC

## Purpose
Sistem digital sederhana untuk membantu operasional masjid, publikasi kegiatan, informasi jamaah, dan administrasi dasar.

## Principles
- Clean, simple, mobile-first.
- Free-tier-first.
- Tidak menyimpan data pribadi yang tidak diperlukan.
- Tidak mengatasnamakan institusi tanpa izin.
- Demo data harus jelas dipisahkan dari data produksi.

## MVP modules
1. Beranda
2. Profil masjid
3. Jadwal/kegiatan
4. Kajian & agenda
5. Pengumuman
6. Donasi/infaq
7. Kontak WhatsApp
8. Galeri
9. Dashboard admin
10. Keuangan sederhana

## Roles
- Public: membaca informasi.
- Admin: mengelola konten.
- Bendahara: mengelola transaksi.
- Pengurus: melihat dashboard.

## Non-goals
- Payment gateway wajib.
- Data pemerintah.
- Data sensitif jamaah.
- Sistem akademik/presensi kompleks.
