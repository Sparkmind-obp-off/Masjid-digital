# PRODUCT REQUIREMENTS

## User stories
- Pengunjung dapat melihat profil dan kegiatan.
- Pengunjung dapat melihat agenda kajian.
- Pengunjung dapat melihat informasi donasi.
- Pengunjung dapat menghubungi pengurus.
- Admin dapat CRUD agenda dan pengumuman.
- Bendahara dapat mencatat pemasukan dan pengeluaran.
- Pengurus dapat melihat ringkasan.

## Acceptance criteria
- Responsif di HP.
- Public tidak perlu akun.
- Admin terautentikasi.
- Semua mutation memiliki timestamp/audit trail.
- Form tervalidasi.
- Loading, empty, dan error states tersedia.
- Dapat dideploy tanpa layanan berbayar wajib.
